Connect to the robot

The running robot controller receives DDS commands on its own loopback interface. This panel opens a persistent SSH connection to the robot and runs its auxiliary DDS publisher there. The password is used for this connection and is not saved.

1 · Choose a robot mode

The G20 controller must have its HOME switch held for DDS control. Select Stand up, then Walk, and arm velocity control below. Mode and velocity messages have no robot acknowledgement in this panel.

2 · Enable velocity controls

Movement controls are disarmed.

Arm enables the panel controls; it is not a robot mode. Hold a direction button or key to move. Releasing it sends zero. Space stops and disarms.

Exact velocity command

After selecting Walk and arming, enter a body velocity and click Start. It runs until you click Stop, change mode, leave this tab, or lose the connection. Direction buttons use the absolute values below.

Changing a field while running takes effect after you stop and start again.

vx 0.00vy 0.00wz 0.00

Connection and stop behavior

  1. The panel listens only on this computer's 127.0.0.1 address.
  2. It sends velocity updates every 100 ms while a direction is held or entered velocity is running. The robot-side publisher sends zero after 350 ms without a fresh command.
  3. Releasing a direction, stopping entered velocity, or pressing STOP sends zero. Losing focus sends a stop request; closing the tab triggers the robot-side 350 ms timeout. Keep the G20 remote available if the host or network fails.

DDS topics: rt/ltr/sportmode_cmd · rt/ltr/vel_cmd. The readout shows commands sent by this panel, not measured robot speed.
